## Additional frameworks synthesized from retail operations practice

- Inventory reconciliation equation: opening + inward + saleable returns - sales - damaged - reserved - transfers = expected closing.
- ATP equation: physical stock - reserved - damaged/blocked - safety buffer = available-to-promise.
- Reorder logic: weekly sales × (lead time weeks + safety weeks) - current saleable stock - on-order.
- Contribution logic: ASP - product cost - commission - logistics - return provision.

These formulas are applied to realistic fashion retail examples rather than copied from any single source.
