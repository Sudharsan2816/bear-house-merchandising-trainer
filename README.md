# The Bear House Merchandising Interview Trainer

A practical React/Vite training site for The Bear House Buying & Merchandising internship preparation.

Focus areas:

- Fashion retail business flow
- Inventory thinking and SKU-level decisions
- Retail math: ST%, WOS, GMROI, IMU, markdowns, OTB, stock-to-sales
- Excel logic for merchandising dashboards and reconciliation
- Omnichannel operations across D2C, Myntra, Ajio, Amazon and offline
- ERP workflows: BOM, PO, GRN, warehouse stock, returns and inventory sync
- Assortment planning, replenishment, OTB and forecasting
- QA concepts: 4-point fabric system, AQL, shrinkage and garment defects
- Interview reasoning drills and business tradeoffs

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

The project is Vercel-ready. Build command: `npm run build`. Output directory: `dist`.
